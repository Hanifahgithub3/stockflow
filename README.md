# StockFlow – Inventory Management System

StockFlow is a web-based inventory management system built to support product management, supplier administration, and purchase order tracking.

## Key Features
- Dashboard with inventory statistics
- Product and category management
- Supplier management
- Purchase Order creation and tracking
- Stock monitoring and low-stock indicators
- Role-based access control

## Tech Stack
- Laravel
- PHP
- MySQL
- Bootstrap 5
- JavaScript

## Project Purpose
Developed as a portfolio project to demonstrate web application development, database management, inventory workflows, and business process understanding.
